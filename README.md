# Retail Store Data Analysis Using SQL

## Project Overview

This project focuses on analyzing retail store data using SQL. It uses a relational database to answer practical business questions related to customers, products, orders, payments, and customer reviews.

The project demonstrates how SQL can be used to organize, retrieve, filter, and analyze data for business decision-making.

## Project Aim

To transform structured retail data into meaningful business insights using SQL queries.

## Tools & Technologies

* MySQL 8.0
* MySQL Workbench
* SQL

## Database Structure

The database contains six tables:

| Table           | Description                                    |
| --------------- | ---------------------------------------------- |
| customers       | Customer information                           |
| products        | Product details, categories, prices, and stock |
| orders          | Customer order records                         |
| order_items     | Products and quantities within orders          |
| payments        | Payment information                            |
| product_reviews | Customer ratings and feedback                  |
